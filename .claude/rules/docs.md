# 저장소 문서 문체 — snapdone 추가 기준

기본 문체(개조식 · 명사형, 체언 제목, `- **주제** — 설명`, 바꾸지 않는 것)는 생성 rule `_generated/docs-ko.md`. 적용하지 않는 문서는 `.claude/harness.profile.md`. 여기에는 snapdone이 더하는 것만 둔다.

- 명사형 종결의 예 — `~음` · `~함` · `~임` · 체언("읽지 않음", "교체", "검사 대상에서 제외")
- `~하는 것이다` · `~해야 했다` · `~게 됐다` 같은 늘어지는 종결은 쓰지 않는다
- 제목 — 나쁨 `온보딩 소개 화면을 스크린 리더가 완료로 읽게 고쳤다`, 좋음 `온보딩 소개 화면을 스크린 리더가 완료로 읽도록 수정`
- 목록 항목 끝에 마침표를 찍지 않는다
